## Dental Palace - Dental Management System

A web-based Dental Management System developed using PHP, MySQL, HTML, CSS, and JavaScript.

### Features
- Admin, Employee & Customer Management
- Appointment Management
- Billing Management
- Equipment Management
- Dental Services Management
- User Registration & Login

### Technologies
PHP | MySQL | HTML | CSS | JavaScript | XAMPP
